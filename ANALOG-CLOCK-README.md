🕒 Analog Clock
  
A stylish, real-time Analog Clock built using HTML, CSS, and JavaScript. It displays the current local time with hour, minute, and second hands in a modern dark-themed interface.

✨ Live Demo

🔗 https://er-tanmayjain-23.github.io/Analog-Clock/

📸 Features

- 🕐 Real-Time Clock — Displays the current system time.
- 🎨 Modern UI — Elegant dark background with a glass-like clock face.
- 🔴 Colorful Hands — Distinct colors for hour, minute, and second hands.
- 🔢 Numbered Dial — Displays all 12 hours.
- 📱 Simple & Lightweight — No external libraries or frameworks required.
- 🌐 Live Deployment — Hosted using GitHub Pages.

🛠️ Technologies Used

HTML5 - Structure of the clock
CSS3 - Styling, layout, and clock design
JavaScript - Real-time time calculation and hand rotation
GitHub Pages | Hosting and deployment |

⚙️ How It Works

1. JavaScript retrieves the current time using `Date()`.
2. The hour, minute, and second values are extracted.
3. Each clock hand is rotated to the correct angle.
4. `setInterval()` updates the clock every second.
5. No additional dependencies or installation are required.
